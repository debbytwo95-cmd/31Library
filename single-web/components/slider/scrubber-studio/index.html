一条轨道，三层反馈A value at your fingertips

01 / MAP

位置映射数值

点击或拖动轨道，将横向位置映射到数值范围，再按步长吸附。边缘始终能到达最小值和最大值。

02 / REVEAL

弹性显现

悬停或拖动时，4 × 22 px 的手柄从 70% 展开，透明度随弹簧变化。离开后收拢，静止时不计算动画。

03 / READ

即时读数

填充和数值跟随操作，刻度均匀分布。方向键逐步调整，Home／End 到达范围两端。

使用与接入

支持鼠标点击、拖动、触屏和触笔。Tab 聚焦后，方向键按步长调整，Home／End 到达首尾；手柄展开提供键盘聚焦反馈，操作时不显示外描边。触屏不模拟悬停；取消、失焦和切换后台会清理临时状态。开启“减少动态效果”时立即更新。

放置组件 HTML、引入隔离样式，再调用 LibraryScrubber.mount(root, config)。配置支持 label / min / max / step / decimals / ticks / width / value 和 onValueChange(value)。返回实例提供 value、setValue(value)、update(config)、settle()、reset()、destroy()；多实例独立，移除前调用 destroy()。程序配置更新不触发数值回调，setValue 默认触发。

无第三方运行库；下载示例内嵌 Inter 字体与 OFL 许可，可直接打开。重置恢复默认参数及 0.50，保留主题与预览／代码页签。工作台通过 HTTP 访问以读取交付资源。
