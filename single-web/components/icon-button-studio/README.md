# Icon Button Studio

圆形扩散与箭头穿梭的按钮项目。页面、按钮样式、参数调节脚本、图标和字体均在当前文件夹中，可整体复制。

在当前文件夹运行 `npm run dev`，打开 `http://127.0.0.1:4174/`。无需安装依赖，需要本机已有 Node.js。

- 演示区主题切换仅显示图标，支持浅色与深色。
- Get started 字号为 16px，按钮宽度、文字与图标间距自动适配。
- 可调整时长、箭头延迟、圆形大小、箭头位移、圆角与缓动曲线。
- 预览、复制和下载的 HTML 均仅响应真实操作，无自动演示。
- 复制或下载输出为包含当前参数与主题的独立 HTML。

`index.html` 为页面入口；`button.css` 为按钮样式；`app.js` 为交互和参数；`styles.css` 与 `studio.css` 为页面布局；`assets/` 为本地图标和字体；`server.mjs` 为本地预览服务。
