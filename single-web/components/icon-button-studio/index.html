一次经过，三层变化The anatomy of a hover

01 — 03
01 / EXPAND

圆形，展开成底色

从右侧图标圆心出发，底色自然扩散，
铺满整个按钮。

02 / PASS

箭头，轻轻穿过

原有箭头向右移出，新箭头从左进入，
在细节里表达前进。

03 / RETURN

离开，收回到一个圆

鼠标移开，底色收回，箭头复位，
安静等待下一次经过。
