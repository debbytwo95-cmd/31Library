自定义地平线入场 2.4 s · WebGL

原理与使用

用 WebGL 片元着色器生成弧形亮度场，按固定间距采样圆形网点。暗部网点细小，接近地平线时逐渐变大并融入平滑渐变，固定的胶片颗粒让过渡更自然。支持四个方向、单色与六色渐变。依据 uibrik 的公开预览独立复刻，未使用其 Pro 源码。

鼠标经过深色区域也会显出放大的圆点透镜，暖色柔光稍后跟随，并沿路径留下逐渐缩小、淡出的网点笔迹；点击发出网点涟漪；触屏按住移动，松手或取消后复位，页面仍可纵向滚动；键盘聚焦后按 Enter 或空格触发中心涟漪。系统开启减少动态效果时保留即时透镜，关闭拖尾与涟漪。没有 WebGL 时降级为静态渐变。

首次进入视口时，从暖白底开始，用 2.4 秒展开暗部与半调网点；入场时长设为 0 可关闭。入场结束后停帧，只响应真实交互。“重播入场”按当前参数重放，重置则直接回到静止构图。索引封面保持初始静止；系统减少动态效果时跳过入场。复制完整组件代码放入页面，容器宽高决定背景尺寸，可在其中叠放内容。多实例各自独立；通过 root.libraryComponent.update({...}) 更新参数，replayIntro() 重播入场，reset() 清除交互并结束入场，移除前调用 destroy() 清理资源。
