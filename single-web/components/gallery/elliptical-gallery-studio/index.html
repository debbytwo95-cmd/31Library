交互与接入

默认自动旋转。悬停或 Tab 聚焦色块使轨道减速停驻，当前块放大；移出恢复。鼠标或触屏水平拖拽改变相位，触屏纵向仍可滚动页面。点击色块或空格切换暂停与继续，左右键步进，Home／Escape 复位并暂停。重置恢复默认参数、保留主题与页签，点击参数区“继续旋转”恢复。

页面失焦、隐藏、代码页签或滚出视口时暂停；恢复可见后继续。减少动态效果时停止自动旋转和放大过渡，保留拖动和键盘操作。图片和视频全部替换为纯色块，没有中央文案、图标、卡片标签或图片资源。

放置 .library-elliptical-gallery 容器，引入一次 CSS 和脚本，调用 LibraryEllipticalGallery.mount(root,config)。提供 update/reset/pause/resume/getConfig/destroy，多实例独立；删除节点前调用 destroy 清理事件、动画和观察器。重复挂载自动销毁旧实例。

原生 HTML、CSS、JavaScript、ResizeObserver 与 IntersectionObserver，无第三方运行库和外部资源。复制代码、提示词与下载示例同步当前参数、方向、配色及主题。下载 HTML 可直接打开；工作台通过 HTTP 访问。
