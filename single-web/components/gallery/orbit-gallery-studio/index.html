02 / ORBIT

指尖转向

鼠标移动产生轻微视差，拖拽或方向键旋转。鼠标离开时收回临时视差，保留主动旋转后的角度。

03 / FOCUS

一张成为焦点

点击作品后放大到中央，周围图像淡出。再次点击、点击空白、关闭按钮或 Escape 返回画廊。

交互与接入

鼠标移动产生视差；鼠标或触屏水平拖拽旋转，触屏仍可纵向滚动页面。Tab 选择图像，Enter／空格放大；方向键旋转，Home 回到初始角度。画廊取得焦点后可用滚轮旋转，未聚焦时滚轮正常滚动页面。Escape 或关闭按钮退出聚焦；失焦、取消和隐藏页面会清理拖拽。系统减少动态效果时关闭悬停视差与过渡，拖拽、键盘及聚焦功能仍可使用。没有自动旋转、自动演示或闲置循环。

放入 .library-orbit-gallery 容器，引入一次 CSS 和脚本，调用 LibraryOrbitGallery.mount(root, config, items)；每项包含 src、title 和可选 category。提供 update(config)、reset()、close()、getConfig() 和 destroy()。同页多个实例独立，移除容器前调用 destroy 清理事件、观察器及动画。重复挂载自动销毁旧实例。

原生 HTML、CSS、JavaScript、ResizeObserver 与 Web Animations API，无第三方运行库。封面、预览及交付共用同一实现，重置保留主题与页签。下载单文件 HTML 可直接打开；仓库工作台通过 HTTP 使用。图片与 Inter 字体内嵌，字体附 SIL OFL 许可。
