01 / APPROACH

靠近，自然被吸引

进入吸附范围，按钮向光标轻轻偏移。
距离越近，引力越清晰。

02 / FOLLOW

跟随，多一点层次

按钮与文字以不同幅度追随光标，
在平面里，创造细微的空间感。

离开，弹性回到原点

弹簧模拟带来柔和的回弹与停顿，
每次交互，都有一个轻盈的落点。
