# Magnetic Button · 磁吸按钮

由 Motion Studies · 磁吸按钮项目复制的 GitHub Pages 静态版本。页面、字体和图标均在本目录，磁吸交互与动效脚本保持原样。

- 入口：`index.html`。
- 组件索引使用：`./single-web/components/magnetic-button-studio/index.html`（相对于仓库首页；组件目录索引已有 `../../` base）。
- 页面内样式、脚本、字体和图标全部使用相对路径，兼容 GitHub Pages 的仓库子路径。
- 页头 Logo 返回仓库首页，“组件”与面包屑返回上一级组件索引。
- 静态托管无需 Node.js、安装依赖或构建。项目仍可用 `npm run dev` 本地运行。
- `app.js`：原始磁吸、弹簧、预设、慢速、主题与代码导出逻辑。
- `shell.js`：页头搜索。
- `reference/`：原始文档、导出示例与页面布局参考。

源站：https://magnetic-button-studio.candybull5.chatgpt.site
