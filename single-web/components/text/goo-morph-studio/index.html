一个词，三段变化Blur into shape

01 / BLUR

模糊离场

旧词逐渐模糊并淡出。变化使用 smoothstep 曲线，起止保持平滑。

02 / FUSE

液态融合

新词从模糊中显现；SVG 透明度阈值让重叠边缘融合成黏连的文字轮廓。

03 / REST

清晰停驻

到达后移除阈值滤镜，还原平滑文字边缘，停止动画帧，停留后自动进入下一次变形。

使用与接入

页面打开后自动循环轮换词组：默认停留 1600ms，再用 1050ms 液态变形。点击、轻触或 Enter／空格可立即切换，变形中不累积切换。移出文字区域后继续自动播放；取消时结束临时动效，窗口失焦时继续播放，页面隐藏或切换代码页签时暂停，返回后重新等待完整停留时间。索引封面同样自动轮换，无需点击或悬停，指针移出后继续播放。参数调整与重置后回到首词，按当前停留时间继续轮换。减少动态效果时按相同停留间隔直接切换。窄容器按最长词组自适应字号。

放置交付结构，引入一次 CSS 与脚本，调用 LibraryGooMorph.mount(root, config)。实例提供 next()、update(config)、reset()、finish()、play()、pause()、destroy()；多实例独立，移除前调用 destroy。SVG 滤镜标识由实例自动生成。原生 HTML、CSS、JavaScript 与 SVG 滤镜，无第三方运行库。预览使用仓库 Inter Semibold，交付内嵌同一字体与许可；中文采用系统字体回退。下载 HTML 可直接打开，工作台需通过 HTTP 使用。

参考：DesignBookmark · Goo Morph（用户提供的参考源码）。按用户要求自动循环播放，并保留点击切换。
