使用与接入

正文保持完整句子与标点，姓名 Evelyn Gao 和项目名 31Library 可选择；透明选框不填色、不改变文字颜色，尺寸标签保留蓝底白字。Tab 聚焦，左右方向键及 Home / End 在选区间移动；Enter、空格或轻触选择，Escape 清除。触屏不模拟悬停方向。移出、取消、失焦、页面隐藏或切换代码页签时清除状态并恢复提示，减少动态效果时直接切换。重置恢复默认参数与静止初态，保留主题和页签。

放置 .library-direction-selection 容器，引入一次 CSS 和脚本，再调用 LibraryDirectionSelection.mount(root, config)。实例提供 update(config)、reset() 与 destroy()；支持多实例，重复挂载自动清理旧实例，移除前请销毁。

原生 HTML、CSS、JavaScript 与 ResizeObserver，无第三方运行库。工作台通过 HTTP 运行；下载 HTML 内嵌同一效果、Inter 和 Caveat 字体及各自许可，可直接打开，中文使用系统字体。四角手柄属于选区内容，手绘箭头属于文字标注插图。参考：Aceternity UI / Direction Aware Selection，根据公开预览独立实现。
