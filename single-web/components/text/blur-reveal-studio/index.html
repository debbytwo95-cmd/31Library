所有参数实时生效

从柔焦，到清晰逐字显现的三个阶段

01 / SOFTEN

柔焦起笔

每轮开始时，各字从透明与模糊状态开始；真实操作也可立即重新播放。

02 / REVEAL

逐字显现

从左到右错开启动，透明度与模糊同步恢复。缓动收住尾段，无位移或缩放。

03 / REST

清晰停驻

到达后清晰停驻 1400ms，再自动开始下一轮；窗口失焦或页面隐藏时暂停。

使用与接入

无需点击即可自动播放，每轮完成后停驻 1400ms。悬停、点击、轻触或 Enter／空格立即重播；移出或取消后清晰复位，再继续循环。窗口失焦、页面隐藏或切换代码页签时暂停，恢复后继续。重置恢复默认参数并暂停，操作文字或切回预览恢复播放。参数调整后等待 1400ms 开始；减少动态效果时保持清晰文字，不播放模糊。支持中文、组合字符及长文本自然换行。

放置交付结构，引入一次 CSS 和脚本，调用 LibraryBlurReveal.mount(root, config)。实例提供 play()、update(config)、reset()、resume() 和 destroy()。多个实例独立运行，移除容器前调用 destroy 清理事件与动画；重复挂载会自动清理旧实例。

基于原生 HTML、CSS、JavaScript 与 Web Animations API，无第三方运行库。预览使用仓库 Inter Semibold，交付内嵌同一字体与许可；中文采用系统字体回退。下载 HTML 可直接打开，工作台通过 HTTP 使用。复制代码、示例与提示词均同步当前文字、字号、时长、间隔、模糊及主题。
