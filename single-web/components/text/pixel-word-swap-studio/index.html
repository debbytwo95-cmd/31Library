调试你的参数

悬停标题时按原站节奏循环换词，移出后完成当前切换即静止；点击、轻触或 Enter／空格立即换到下一个词。

最多 12 个词，每个 40 个字符；留空时保留上次内容。

所有参数实时生效

一个词，三段节奏Hold · Pixelate · Reflow

01 / HOLD

停留与触发

静止时显示首个词。悬停标题立即换词，之后每个词停留 1300ms 再切换；移出后完成当前切换即停住。点击可随时换到下一个词。

02 / PIXELATE

马赛克换词

650ms 内像素块按正弦曲线从 1px 增至字号的 12.5%，再回到清晰；在最粗的中点替换单词。词槽先按块缩小采样，再关闭平滑放大。

03 / REFLOW

句子让位

词槽宽度以 easeInOutCubic 在新旧词宽之间过渡，每行重新居中，前后文字随之平移。换行按最长词预留，切换时不跳行。

使用与接入

页面打开后保持静止，只显示第一个词。鼠标或触控笔悬停标题时立即换词，并按停留 1300ms、切换 650ms 的节奏循环；移出后完成当前切换再停住。点击、轻触或 Enter／空格立即换到下一个词，切换进行中连续操作最多排队一次。打开“自动轮换”后，不需要悬停也会按原站节奏持续循环。系统开启“减少动态效果”时直接换词，不显示马赛克。失焦、页面隐藏或切到代码页签时停止计时；返回后，开启自动轮换时继续循环，否则等待真实操作。窄容器按最长词预留宽度自动换行。

将交付结构放入目标页面，引入一次样式和脚本，再调用 LibraryPixelWordSwap.mount(root, config)。返回 next()、play()、pause()、update(config)、reset()、refresh() 和 destroy()；支持多实例独立运行，移除实例前请销毁，以清理事件、观察器、计时器与动画帧。文字绘制在 Canvas 2D 上，按钮保留完整句子作为可访问名称。原生 HTML、CSS、JavaScript，无第三方运行库；标题使用仓库内 Source Serif 4（SIL OFL 1.1）替代原站商用字体，交付内嵌同一字体及许可。中文词组使用系统衬线字体回退。
