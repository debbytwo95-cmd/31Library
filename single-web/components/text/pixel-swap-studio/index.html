一个词，三段变化来自 Melius 标题的文字转场

01 / PIXELATE

像素化

每次停驻 1300ms 后，中间词由清晰笔画渐变为像素块。句子两侧始终保持清晰。

02 / SWAP

换词与重排

转场中点替换内容，词槽宽度按三次缓动变化，整句持续居中。

03 / RESOLVE

清晰落定

像素块重新收细为清晰文字，停驻后继续轮换；真实操作可立即切换。

使用与接入

默认自动轮播，每次清晰停驻 1300ms 后换词，无需鼠标经过。悬停、点击、轻触或 Enter／空格可立即切换；移出或取消复位后继续轮播。Escape 或重置恢复首词并暂停，再次真实操作或切回预览恢复。失焦、隐藏或代码页签暂停，返回后继续。快速操作不堆积动画；重置保留主题与页签。减少动态效果时停止自动轮播，手动直接换词。窄屏按最长词预留换行位置，长词自动缩小。

放置交付容器，引入一次 CSS 和脚本，调用 LibraryPixelSwap.mount(root, config)。实例提供 next()、update(config)、reset()、pause()、resume() 和 destroy()；多个实例独立运行，重挂载自动清理旧实例，移除前调用 destroy 清理事件、动画与观察器。

使用原生 HTML、CSS、JavaScript、Canvas 2D 与 ResizeObserver，无第三方运行库。字体遵循仓库 Inter Regular / Noto Sans SC 规范。复制代码自带当前内容所需字体与许可；下载源码包解压后直接打开 index.html，保留 assets 目录。工作台需通过 HTTP 访问。
