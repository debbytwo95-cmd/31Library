调试你的参数

闲置时自动左右扫动，鼠标经过时跟随指针，移开后继续播放。

所有参数实时生效；峰值字重始终不小于基础字重

字母之间，流动的重量Weight in motion

01 / DISTANCE

距离决定字重

按每个字母与指针的水平距离计算高斯曲线。靠近波峰时从 300 增重至 820，同时从 42% 不透明度渐亮。

02 / SPRING

双层弹簧跟随

波峰用 150 / 22 的弹簧追随指针，每个字母用独立弹簧改变字重。Inter 可变字体保留连续、细腻的粗细变化。

03 / FLOW

闲置自动流动

波峰以约 4.6 秒为周期往返扫动。指针进入时优先跟随操作，离开后从当前波峰平滑接续；减少动态效果时关闭自动扫动。

使用与接入

没有鼠标经过时，波峰以约 4.6 秒为周期左右往返。鼠标在文字附近移动时接管波峰，移开后恢复自动播放。键盘 Tab 聚焦文字后，方向键移动波峰，Home / End 到达两端，Escape 或文字失焦后恢复自动播放。触屏按住并水平移动，松手、滚动取消后恢复扫动，保留纵向滚动。窗口失焦、隐藏、离页和代码页签暂停动画，返回后继续。重置恢复默认参数并暂停，保留主题与页签；再次操作文字或返回预览后恢复播放。

将组件结构放入页面，引入一次样式与脚本，再调用 LibraryWeightWave.mount(root, config)；实例提供 update(config)、reset()、play()、pause()、destroy()。多个实例独立工作，移除前销毁以清理监听、观察器与动画。原生 HTML / CSS / JavaScript，无运行库依赖；效果依赖完整字重轴的 Inter Variable，已随单文件 HTML 内嵌及附上 SIL OFL 许可。示例下载后可直接打开，无需构建。预览通过 HTTP 使用仓库字体，中文采用系统字体回退，字重连续性取决于回退字体。窄屏自动缩小长句。
