使用与接入

支持鼠标、触屏，以及 Tab 聚焦后的 Enter／空格激活。演示区只展示按钮，示例复制内容为 npm i motion-kit，接入时可通过配置中的 command 修改。默认静止；系统开启“减少动态效果”时直接切换状态。复制失败时通过状态提示告知。剪贴板 API 需要 HTTPS 或 localhost，其他环境尝试浏览器的传统复制能力。

将交付代码的结构放入目标页面，引入一次样式和脚本，再调用 LibraryCopyButton.mount(root, config)。多实例独立运行，支持 update(config)、reset() 与 destroy()，移除实例前请销毁。修改参数、页面失焦或离开会清理临时状态。复制及下载中内嵌仓库的 copy.svg、check.svg 和 Inter 字体，无外部运行库。
