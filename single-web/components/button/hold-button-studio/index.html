使用与接入

鼠标、触屏按住或键盘 Tab 聚焦后长按空格／Enter 均可操作。松开提前取消，页面失焦或触点取消也会清理按压状态；完成后会自动回到初态。开启系统“减少动态效果”后，仍可长按触发，但回弹与形变改为即时反馈。

组件采用独立类名、原生 CSS 与 JavaScript，无额外运行库。可在页面放置多个独立按钮实例；通过 button.libraryComponent.update(config) 更新参数，reset() 重置，移除组件前调用 destroy()。长按完成只提供 onComplete 回调，示例不会实际发布数据。
