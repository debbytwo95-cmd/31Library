使用与接入

鼠标从四个方向移入或离开；键盘 Tab 聚焦展开，Enter / 空格激活；触屏按住展开、松手收回。触屏不模拟悬停。系统减少动态效果时直接切换填充状态。

复制结构、样式和脚本后即可使用，GSAP 3.15.0 与 Inter Semibold 字体已内嵌。多个实例独立运行；重置调用 root.libraryComponent.reset()，移除前调用 root.libraryComponent.destroy()。示例保存后可直接打开。
