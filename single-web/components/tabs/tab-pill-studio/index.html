使用与接入

鼠标点击、触屏轻触、键盘 Enter／空格均可选择。Tab 聚焦选中项后，左右方向键循环切换，Home／End 到达首尾。系统开启“减少动态效果”时立即切换。慢速观察仅影响工作台；重置恢复默认参数和首项，保留演示主题与预览／代码页签。

放置组件 HTML、引入隔离样式，再调用 LibraryTabPill.mount(root, config)。返回实例提供 select(index)、update(config)、reset()、destroy() 与 onChange(index, tab) 初始化回调。多个实例独立运行，移除前调用 destroy()。示例仅展示标签栏，关联内容为屏幕阅读器保留；接入实际内容时替换面板并移除面板的视觉隐藏样式。

无第三方运行库，下载的 HTML 可直接打开。
