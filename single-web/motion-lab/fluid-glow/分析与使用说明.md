# uiuxarih 光效流动复刻

直接用 Chrome / Edge 打开 `index.html`，不需要安装依赖或构建。也可在本文件夹启动静态文件服务器。当前预览地址：http://127.0.0.1:8765/index.html 。

## 视频观察

参考文件为 `uiuxarih.mp4`，2560 × 1268，约 10.32 秒。主体是黑色网站页脚上方的橙白色弧形光带。光带沿水平方向展开，中间高、两边低；细线的间距和交点随时间变化，中心区域汇聚成暖白色亮带，外侧保留红橙光晕。上方还有非常暗的弧形残光，附近有少量细碎亮点。

这里需要同时还原三件事：稳定的弧形外轮廓、错相运动造成的细线交织、亮度叠加造成的过曝和扩散。仅仅移动一个渐变背景，很难获得原视频两端细线交错的结构。

## 本次代码实现

采用原生 Canvas 2D，每帧通过 `requestAnimationFrame` 更新。所有光线均由代码绘制；原视频仅用于对照，不参与复刻画面的渲染。

### 曲线骨架

逻辑画布宽 1440，高约 713，保持参考视频比例。18 条曲线共享一个抛物线式弧形轮廓：

```text
x = 1440 × (0.5 + 0.6u)
y = 188 + 88 × curvature × u² + (i − 8.5) × spacing + 1.675
    + A(u) × sin(1.7t − 9u + 0.72i)
    + 0.21A(u) × sin(0.54(1.7t − 9u + 0.72i) + 0.6i)
A(u) = (3 + 28|u|^1.8) × weave
```

`u` 是曲线横向位置，`i` 是光轨编号，`t` 是累计动画时间。`u²` 给出稳定的拱形；不同的 `i` 引入相位差；`A(u)` 让中部更稳定、两端更明显地交织。沿线移动的短亮段额外提供流动感。参数是针对画面效果调出的近似值，不是从原工程提取的数据。

### 光效合成

1. 在离屏画布中画出细光轨和中心热亮带。
2. 用 `source-in` 把同一层分别染成红、橙和浅橙。
3. 分别施加约 30、11、3.5 个逻辑像素的模糊，以 `lighter` 加色方式叠回主画布。
4. 叠加未经模糊的暖白细线，保留清晰结构；密集处会自然趋向白色。
5. 加入很弱的椭圆环境光、上方残光和缓慢运动的微粒。

没有将上一帧持续累积到下一帧，避免随帧率变化产生不同的拖影长度。运动依据经过的时间更新。画布随容器和设备像素比调整，像素比上限 1.75，以限制模糊层开销。系统开启减少动态效果时默认暂停。

## 操作与修改

- **暂停 / 播放**：冻结当前动画画面。
- **流速**：改变动画时间推进速度。
- **交织**：改变波动幅度；设为 0 可看到纯弧形光轨。
- **辉光**：改变模糊叠加层强度；中心亮带仍保留。
- **光效颜色**：点击色块自由选色，或使用橙、蓝、青、紫、粉五种预设；光轨、三层辉光、环境光与微粒会同步变色，核心仍保留接近白色的高亮。↺ 同时恢复默认橙色。
- **光线间距**：直接控制 18 条光轨的纵向基准间距，范围为 0–12 个设计像素，默认 3.35；随画布宽度等比缩放。数值越大，光线越疏，整体光带越宽；数值越小，光线越密。光带中心保持固定。交织仍独立生效，因此间距为 0 时不同相位的曲线也可能分开。点击「拆解光轨」可更清楚地观察每根线的位置。↺ 恢复 3.35。
- **弯曲度**：范围 0–200%，默认 100%。0% 将弧形骨架变为水平，200% 加强拱形；光带中心高度不变。光轨、流动亮段、中心亮带和上方残光使用同一弯曲参数。交织仍独立生效，要观察纯水平光线可同时将交织设为 0。↺ 恢复 100%。
- **光带位移**：水平范围 −720 至 +720，垂直范围 −300 至 +300，单位为 1440px 设计画布的逻辑像素，随预览宽度等比缩放。负值向左／向上，正值向右／向下。整组光轨、辉光、氛围和微粒作为一个图层移动，页面文字位置不变；超出预览范围的部分被裁切。「归位」只将两项位移归零，↺ 恢复全部参数。
- **光带粗细**：提供「粗」「细」「随机」模式，分别使用 5、2.1、3 个设计像素作为初始基础宽度，滑块可在 0.3–8 之间微调。「粗」「细」让每条光线使用相同宽度；「随机」为每条光线分配 0.25–2 倍基础宽度的随机倍率，动画期间保持稳定，点击「重新随机」才更换分布。流动亮段同步使用所属光线的宽度，中心亮带随基础宽度调整。拆解模式同样显示真实粗细。↺ 恢复「细」模式和 2.1。
- **拆解光轨**：同时关闭辉光、中心热亮带和氛围层，以细线展示曲线结构。
- **对照原视频**：显示原视频；这是视觉对照，并非逐帧同步。
- **↺**：恢复参数，并把复刻的动画时间归零。

`light.js` 中 `point()` 控制轮廓与交织，`drawStrands()` 控制线条，`render()` 控制辉光叠加。`style.css` 控制配套页脚和操作面板。Newsletter 只是排版演示，不会发送或保存邮箱。

## 验证与边界

已进行 JavaScript 语法检查，并在浏览器检查光效渲染、暂停、曲线拆解、原片对照和参数控制。此实现主要复刻光效语言，字体、标志、细线运动周期与原片不是逐像素一致。仅凭成片无法确定原作者使用的是 WebGL Shader、三维发光曲线还是后期合成，以上是可复现相似视觉的一种实现方式。
