原理与使用

先用画布排出 31Library 图标与字标，把蒙版转换为有符号距离场。片元着色器沿每个像素向画面深处步进，标志在每一层深度按流动路径平移，首次相交处就是挤出侧壁；路径由一个朝向平滑转动的运动体积分得到，每个字形按横向位置错开相位，于是拖尾时而下垂、时而上扬或横扫。侧壁法线由距离场梯度和路径切向合成，近正面主光与顶光给出缎面高光；第二遍按深度做景深模糊，正面保持清晰，再叠加辉光与胶片颗粒。分区标注用独立的 2D 画布绘制，随流动时间确定性地出现、跳号与淡出。

页面打开时停在静止构图。点击“播放流动”开始连续流动，再次点击暂停；鼠标在画面上移动会拖动拖尾，停下后约一秒收回，触屏按住拖动，松手或取消后收回，页面仍可纵向滚动。播放按钮支持 Tab 聚焦与 Enter／空格；拖尾拖拽依赖指针，键盘不模拟指针。切到代码页签时暂停，系统开启减少动态效果时流动降为三成速度、指针拖拽降为四分之一。没有 WebGL2 时降级为 Canvas 2D 静态叠层。

复制组件代码放入页面，容器宽高决定画面尺寸；交付内嵌 Inter Semibold 与许可，标注字体使用系统等宽字体。多实例各自独立，通过 root.libraryComponent.update({...}) 更新参数，play(true|false) 播放或暂停，reset() 回到静止构图，移除前调用 destroy() 清理事件、观察器、动画帧与 WebGL 资源。视觉参考：secondeight_ 发布的 Sixfold 标志动效视频，标志已替换为 31Library；这是根据画面建立的模型，不代表原作者的技术实现。
